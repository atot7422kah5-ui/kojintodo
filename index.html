設定・データ

PC・スマホの同期

アプリを開いたときの画面

「Vision」にすると、毎朝アプリを開いたときに最初にビジョンボードが表示されます（この端末だけの設定です）。

表示テーマ
カガミ連携（日記を GitHub に送る）

日記を書くと、指定した GitHub リポジトリに1日1ファイルで送ります。トークンはこの端末だけに保存され、同期やエクスポートには含まれません。PC とスマホで使う場合は、それぞれの端末で保存してください。

データのバックアップ

データはこのブラウザ内（localStorage）に保存されます（同期中はクラウドにも保存）。定期的なバックアップや、同期を使わずに別の端末へ移すときはエクスポートをご利用ください。

お試し
データの削除

すべての Daily・ToDo・日記・Vision を削除します。元に戻せないため、必要に応じて先にエクスポートしてください。
