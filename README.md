# kojintodo（Kojin ToDo）

個人用のタスク管理・ToDo管理アプリです。
毎日のルーティン（Daily）、通常のToDo、重要度×緊急度の4象限マトリクスを1つの画面で管理し、**重要な仕事に集中する**ことを目的としています。

HTML / CSS / JavaScript だけで動く静的なWebアプリで、ビルドやインストールは不要です。データはブラウザの localStorage に保存されます。

---

## 主な機能

| 機能 | 内容 |
| --- | --- |
| Dailyタスク | 毎日（または指定した曜日）に繰り返すタスク。完了チェックは日付が変わると自動でリセット。直近7日間の記録と連続達成数を表示 |
| ToDoリスト | 締切日ごと（期限切れ／今日／明日／7日以内／それ以降／期限なし）に自動で整理。未完了・完了を切り替えて表示 |
| 4象限マトリクス | 重要度×緊急度で「今すぐやる／計画してやる／任せる・手早く／やらない・後回し」に分類。PCはドラッグ＆ドロップで移動 |
| 今日（ホーム） | 今日のDaily・期限切れと今日締切のToDo・重要なタスクをまとめて表示し、進捗率を円グラフで表示 |
| 追加・編集・削除 | クイック追加（Enterで即追加）と、締切日・象限・メモまで設定できる詳細ダイアログ。削除は「元に戻す」が可能 |
| 完了管理 | チェックで完了／未完了を切り替え。完了済みタスクの一括削除（元に戻す可） |
| 締切日 | 「今日／明日／1週間後／なし」のワンタップ設定。期限切れは赤、今日締切はオレンジで強調 |
| データ保存 | localStorage へ自動保存。JSON でのエクスポート／インポート（バックアップ・端末間の移行用） |
| PC・スマホ対応 | PCはサイドバー、スマホは下部タブバー＋下から出るシート型のダイアログ。ダークモードにも対応 |

## 画面構成

```
┌──────────────┬──────────────────────────────────┐
│ サイドバー     │  メイン画面                          │
│  ・今日        │   今日     … 今日やることのダッシュボード  │
│  ・Daily       │   Daily    … 繰り返しタスクの管理        │
│  ・ToDo        │   ToDo     … 締切日別のタスク一覧        │
│  ・マトリクス   │   マトリクス … 重要度×緊急度の4象限       │
│  ・設定・データ │                                    │
└──────────────┴──────────────────────────────────┘
※ スマートフォンでは、サイドバーの代わりに画面下部のタブバーで切り替えます
```

画面はURLのハッシュ（`#today` `#daily` `#todo` `#matrix`）で切り替わるため、ブラウザの戻る操作やブックマークにも対応しています。

## 起動方法

### 1. ファイルを直接開く（いちばん簡単）

1. このリポジトリをダウンロード（またはクローン）します。
   ```bash
   git clone https://github.com/atot7422kah5-ui/kojintodo.git
   ```
2. フォルダ内の `index.html` をダブルクリックし、ブラウザ（Chrome / Edge / Safari / Firefox）で開きます。

サーバーやインストールは不要です。

### 2. ローカルサーバーで開く（任意）

Python が入っている環境では、次のコマンドでも起動できます。

```bash
cd kojintodo
```

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### 3. スマートフォンで使う

- **同じWi-Fi内で試す**：PCで次のコマンドを実行し、スマホのブラウザで `http://<PCのIPアドレス>:8000` を開きます。
  ```bash
  python3 -m http.server 8000 --bind 0.0.0.0
  ```
- **常用する**：GitHub Pages などの静的サイトホスティングで公開すると、スマホからいつでもアクセスできます（GitHub Pages はリポジトリの公開設定やプランによって利用条件が異なります）。公開後、Safari の共有メニュー「ホーム画面に追加」でアプリのように起動できます。

> **データの保存先について**
> データは「端末 × ブラウザ × URL」ごとに別々に保存されます。PC とスマホの間で自動同期はされないため、移行やバックアップには「設定・データ」画面のエクスポート／インポートを使ってください。

## 使い方

### タスクを追加する
- 各画面上部の入力欄にタスク名を入力して **Enter**（または「追加」）。
  - 「今日」画面から追加 → 締切が今日のToDo
  - 「ToDo」画面から追加 → 締切なしのToDo
  - 「Daily」画面から追加 → 毎日繰り返すDaily
  - 「マトリクス」の各象限の「追加」欄 → その象限に分類されたToDo
- 締切日・重要度×緊急度・メモ（Dailyは曜日）も設定したいときは「**詳細**」を押します。

### 編集・削除・完了
- タスク名をクリック（タップ）すると編集ダイアログが開きます。削除もここから行えます。
- PCではタスクにマウスを乗せると右端にゴミ箱アイコンが表示されます。
- 左の丸いチェックで完了／未完了を切り替えます。
- 削除した直後に表示される「**元に戻す**」で復元できます。

### マトリクスで優先順位を整理する
- PC：タスクをドラッグして別の象限（または「未分類」）へドロップします。
- スマホ：タスクをタップし、編集ダイアログの「重要度 × 緊急度」で象限を選びます。

### キーボードショートカット（PC）
| キー | 動作 |
| --- | --- |
| `N` | 追加欄にカーソルを移動 |
| `1`〜`4` | 今日／Daily／ToDo／マトリクスに切り替え |
| `Esc` | ダイアログを閉じる・入力欄から抜ける |

## システム構成

### ディレクトリ構成

```
kojintodo/
├── index.html              … 画面の骨組み（ナビゲーション・ダイアログ）
├── css/
│   └── style.css           … デザイン（ライト／ダーク、PC／スマホのレイアウト）
├── js/
│   ├── utils.js            … 日付計算・HTMLエスケープなどの共通処理
│   ├── store.js            … データモデルと localStorage への保存
│   ├── views.js            … 各画面の HTML を組み立てる処理
│   └── app.js              … 画面切り替え・操作イベント・ダイアログ・ドラッグ＆ドロップ
├── assets/
│   ├── icon.svg            … ファビコン
│   └── apple-touch-icon.png … iPhone のホーム画面用アイコン
└── README.md
```

### 処理の流れ

```
 操作（クリック・入力）
        │
        ▼
   app.js ──── store.js の関数を呼ぶ（addTodo / setDailyDone など）
                    │
                    ├─ ① データを更新
                    ├─ ② localStorage に保存
                    └─ ③ 変更を通知
                            │
                            ▼
   app.js が再描画 ── views.js が現在の画面の HTML を生成
```

- データの変更は必ず `store.js` を経由します。将来、外部データベースやクラウド同期に移行する場合は `store.js` の `load()` / `persist()` を差し替えることで、画面側を変更せずに対応できる構成です。
- ES Modules ではなく通常の `<script>` で読み込んでいるため、`index.html` をファイルとして直接開いても動作します。

### データ仕様（localStorage）

保存キー：`kojintodo:v1`

```json
{
  "version": 1,
  "todos": [
    {
      "id": "uuid",
      "title": "採用広報記事の構成案を作る",
      "memo": "",
      "dueDate": "2026-12-01",
      "quadrant": "q2",
      "completed": false,
      "completedAt": null,
      "createdAt": "2026-11-26T00:30:00.000Z",
      "updatedAt": "2026-11-26T00:30:00.000Z"
    }
  ],
  "dailies": [
    {
      "id": "uuid",
      "title": "応募者・エントリー状況を確認する",
      "days": [1, 2, 3, 4, 5],
      "startDate": "2026-11-26",
      "doneDates": ["2026-11-25", "2026-11-26"],
      "createdAt": "2026-11-26T00:30:00.000Z",
      "updatedAt": "2026-11-26T00:30:00.000Z"
    }
  ],
  "settings": { "theme": "auto" }
}
```

| 項目 | 説明 |
| --- | --- |
| `quadrant` | `q1`=重要×緊急、`q2`=重要×緊急でない、`q3`=重要でない×緊急、`q4`=重要でない×緊急でない、`null`=未分類 |
| `days` | 実施する曜日（0=日曜 〜 6=土曜） |
| `doneDates` | Dailyを完了した日付の一覧。日付ごとに記録するため、日付が変わると自動で「未完了」になります（直近約400日分を保持） |
| `settings.theme` | `auto`（OSに合わせる）/ `light` / `dark` |

- 日付は端末のローカル時刻で `YYYY-MM-DD` 形式に変換しています（日本時間の深夜〜朝9時に日付がずれないようにするため）。
- 読み込み時に不正なデータは取り除き、JSON が壊れていた場合は元データを `kojintodo:v1:broken:<時刻>` に退避してから新しい状態で起動します。

## 動作環境

- Chrome / Edge / Safari / Firefox の最新版（PC・スマートフォン）
- JavaScript と localStorage が有効であること
- プライベートブラウズでは保存できない場合があります（その場合は画面上部に警告を表示します）

## 動作確認の内容

Playwright（Chromium）で以下を自動確認しています（PC 1280px／iPhone 13／iPhone SE 相当の画面幅）。

- ToDo の追加（クイック追加・詳細ダイアログ）、編集、空タイトルの入力チェック
- 完了／未完了の切り替え、削除と「元に戻す」、完了済みの一括削除
- Daily の追加・曜日指定、日付が変わったときの自動リセット、対象外の曜日、連続達成数
- マトリクスのドラッグ＆ドロップ、象限ごとの追加
- 再読み込み後のデータ保持、別タブでの変更の反映
- テーマ切り替え、エクスポート／インポート（不正ファイルの拒否を含む）、全データ削除、破損データからの復旧
- HTML を含むタスク名がスクリプトとして実行されないこと（XSS 対策）
- スマートフォン幅で横スクロールが発生しないこと、コンソールエラーがないこと
